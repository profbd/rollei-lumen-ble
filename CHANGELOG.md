# Changelog

## 0.2.0

- Store and read JSON explicitly as UTF-8 for portable labels, presets and scenes.

- Studio GUI for Rollei Lumen Pocket Bi-Color V2, used with three lights on macOS.
- Individual sliders, numeric controls and off/on with remembered brightness.
- Five customizable persistent presets and named multi-light scenes.
- One-click scene recall, per-scene fades and direct effect launch buttons.
- Linear brightness/temperature fades, fade in/out and breathing, with endpoint hold and repetition.
- Master dimming, blackout/restore and STOP.
- Persistent BLE connections with coalesced writes and an eight-channel preview.
- Standard Python installation, macOS/Windows instructions and an optional macOS setup wrapper.
- English user guide, current three-light screenshot, protocol notes and synthetic tests.

## 0.1.0 — local prototype

- Recovered the V2 light-setting frame from a working iPad connection.
- Confirmed Python control on three lights and software off/on on one.
- Added an explicit-target CLI and offline capture analyzer.
