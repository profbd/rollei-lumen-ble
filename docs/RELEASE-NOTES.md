# Lumen Studio 0.2.0

A local desktop lighting desk for Rollei Lumen Pocket Bi-Color V2.

## Included

- Individual brightness and color-temperature sliders and numeric inputs.
- Five saved, editable presets.
- Named scenes for multiple lights, with one-click recall and timed fades.
- Linear fades, fade in/out and breathing with adjustable timing and repeat.
- Master dimming, blackout/restore and direct light off/on.
- Standard Python packaging and the `lumen-studio` start command.
- English instructions and an eight-light preview mode.

## Install

Download **rollei-lumen-ble-0.2.0-source.zip**, extract it and follow **Install (once)** in the README. Python 3.13 and Bluetooth LE are required for the documented setup. This release uses a Python environment rather than a bundled native application.

Practical use was confirmed with three V2 lights on macOS. Windows installation instructions are included; Windows light operation has not been hardware-tested in this project.
